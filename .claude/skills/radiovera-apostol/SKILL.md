# Поиск пояснений к апостольскому чтению на radiovera.ru

Скрипт `scripts/radiovera_search.py` делает всю работу детерминированно:
разбирает зачало → строит строку поиска → фильтрует выдачу по точному началу → скачивает посты → пишет MD.

## Вход

Строка, как её даёт azbyka.ru / навык apostol-zachalo, например:

```
[Гал. 5:22–6:2](https://azbyka.ru/biblia/?Gal.5:22-6:2), зач. 213: преподобного Сергия (рядовое чтение в этот день не читается) ⟵ готовить проповедь
```

- `Гал.` — сокращённое название книги (может начинаться с цифры: `2 Кор.`, `1 Тим.`)
- `5:22–6:2` — диапазон; `:` отделяет главу от стиха; `5:2–10` — стихи 2–10 одной 5-й главы
- `зач. 213` — номер зачала

Markdown-ссылки и хвост после двоеточия (праздник, пометки) скрипт игнорирует.

## Формат строки поиска

`2 Кор., 188 зач., IX, 6-11`

| Часть | Правило |
|---|---|
| книга | как в источнике, с точкой, затем запятая: `2 Кор.,` |
| зачало | `188 зач.,` |
| глава | римскими цифрами, затем `, ` |
| один стих | `IX, 6` |
| диапазон в одной главе | `IX, 6-11` (обычный дефис) |
| диапазон через главы | `XI, 33 — XII, 2` (длинное тире с пробелами) |

**Тире на сайте непоследовательны**: в заголовках встречаются и длинное (`—`), и короткое (`-`, `–`), с пробелами и без. Поэтому:
- поиск выполняется по нескольким вариантам написания (дефис, длинное тире, с пробелами и без), результаты объединяются без дублей;
- при проверке «точного совпадения» все виды тире и пробелы вокруг них считаются одинаковыми. Цифры, номер зачала и главы по-прежнему должны совпасть полностью.

Примеры: `Гал. 5:22–6:2, зач. 213` → `Гал., 213 зач., V, 22 — VI, 2`; `Рим. 5:2–10, зач. 90` → `Рим., 90 зач., V, 2-10`.

## Порядок работы

1. Запусти скрипт, передав входную строку как есть:

   ```bash
   python3 .claude/skills/radiovera-apostol/scripts/radiovera_search.py "<входная строка>" --out work/YYYY-MM-DD
   ```

   (из корня проекта; на Windows `python` вместо `python3`). Зависимости: `pip install -r requirements.txt` (`requests`, `beautifulsoup4`).

2. Скрипт сам:
   - строит URL `https://radiovera.ru/?s=<строка, url-encoded>&sorting=relevance` (для каждого варианта тире);
   - из каждой карточки `div.card-content` берёт `p.excerpt` и оставляет **только те, текст которых начинается с точной строки поиска** (StartsWith после нормализации пробелов/nbsp и вида тире; `IX, 6-117` не совпадёт с `IX, 6-11`). Остальные результаты — «похожие», их отбрасываем;
   - забирает `a.link-post` из подходящих карточек (дубликаты убираются);
   - если точные совпадения заполнили страницу, листает дальше (`/page/N/?s=…`), пока они не кончатся;
   - открывает каждый пост и берёт `div.single-content` **до** `<hr class="wp-block-separator …">`;
   - **зачало выделяется отдельным блоком-цитатой** (`> …`): абзацы, в которых есть номера стихов `<span style="color: #ff0000;"><sup>N&nbsp;</sup></span>`, склеиваются в один blockquote, а номер стиха выводится как `**N**` (формат меняется константой `VERSE_FMT` в скрипте, например на `<sup>{n}</sup>`);
   - пишет один файл `<строка_поиска>.md`: заголовок `# Вариант N`, под ним ссылка `[Посмотреть](url поста)`, затем текст поста (жирный, курсив, списки сохраняются).

3. Назови пользователю путь к файлу и коротко сообщи, сколько вариантов найдено. Не пересказывай содержимое, если не просили.

## Если что-то пошло не так

- **Код 2, «Точных совпадений не найдено»** — так и скажи пользователю, назови использованную строку поиска и дай ссылку на поиск, чтобы он мог проверить вручную. Не подставляй «похожие» результаты вместо точных. Возможные причины: у книги другое сокращение на сайте или радио не разбирало это зачало.
- **Код 3, ошибка сети / 403** — `radiovera.ru` недоступен из этой среды (нет интернета, корпоративный прокси или VPN блокирует домен). Проверь доступ командой `curl -sI https://radiovera.ru | head -1`. Пока доступа нет, выполни `--dry-run`, чтобы получить строку поиска и URL, и передай их пользователю.
- **Не удалось разобрать вход** — скрипт сообщит, чего не хватает (книга, глава:стих или номер зачала). Переспроси у пользователя только это.
- Если разметка сайта изменилась (классы `card-content`, `excerpt`, `link-post`, `single-content`), поправь селекторы в `parse_exact_links` и `extract_post_text`.

## Полезные флаги

- `--query "2 Кор., 188 зач., IX, 6-11"` — готовая строка поиска, без разбора входа
- `--dry-run` — только показать строку и URL
- `--out DIR`, `--max-pages N`, `--delay SEC`
