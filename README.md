# Проповедь по Апостолу: проект для Claude Code

Перенос инструментов из claude.ai (проект «Апостольское чтение») в локальную папку. Путь: **дата литургии → зачало → текст чтения с переводами → пояснения Радио Вера → диалог → план → проповедь → EPUB для Kindle**.

## Что внутри

```
propoved-claude-code/
├── CLAUDE.md                 правила проекта, которые Claude Code читает при старте
├── README.md                 этот файл
├── requirements.txt          requests, beautifulsoup4
├── check_setup.py            проверка окружения
├── .claude/
│   ├── commands/propoved.md  команда /propoved
│   └── skills/
│       ├── propoved-workflow/        дирижёр всего процесса + сборка EPUB + загрузчик страниц
│       ├── apostol-zachalo/          какое зачало на литургии
│       ├── apostol-chtenie-format/   текст чтения для чтеца + переводы
│       └── radiovera-apostol/        поиск пояснений на radiovera.ru
├── data/                     index.json, apostol.md, apostol_to_md.py (книга архим. Ианнуария)
├── work/                     промежуточные файлы по датам (создаётся в работе)
├── output/                   готовые EPUB для Kindle
├── examples/sample_kindle.md пример входного файла для сборщика EPUB
├── docs/WORKFLOW.md          этапы, контрольные точки, файлы
├── docs/settings.example.json  необязательные разрешения, чтобы Claude Code реже переспрашивал
└── originals-claude-ai/      исходные версии навыков для claude.ai (справочно)
```

## Установка (5 минут)

1. Установите Claude Code по официальной инструкции: https://docs.claude.com (раздел Claude Code).
2. Распакуйте архив, откройте терминал в папке `propoved-claude-code` и выполните:
   ```bash
   pip install -r requirements.txt
   python3 check_setup.py        # на Windows: python check_setup.py
   ```
   Все пункты должны быть `OK`. Блок «Проверка сети» необязателен, но если там 403 или «недоступен», сайты не откроются и из терминала (VPN, прокси, файрвол).
3. Запустите `claude` в этой же папке.

Необязательно: чтобы Claude Code не спрашивал разрешение на каждый запуск скриптов и чтение azbyka.ru, скопируйте `docs/settings.example.json` в `.claude/settings.json`. Если правила не подхватятся, проверьте их командой `/permissions`; без этого файла всё работает, просто будут запросы подтверждения.

## Как пользоваться

В Claude Code, запущенном в корне проекта:

```
/propoved 2026-10-18 обычный приход, 7–8 минут
```

или обычной фразой: «Подготовь проповедь на 18 октября, обычный приход, 7–8 минут». Отдельные шаги тоже работают: «какое зачало на 18 октября», «собери текст апостольского чтения на 18 октября», «найди пояснения на Радио Вера к зач. 213».

Claude остановится на контрольных точках: подтверждение зачала, бриф после диалога, план, готовый текст, отправка. Подробности и список файлов каждого этапа в `docs/WORKFLOW.md`.

## Отправка на Kindle

Готовый файл появится в `output/Propoved_YYYY-MM-DD.epub`. Два способа доставки:

- письмом с вашего адреса на `имя@kindle.com` (адрес отправителя должен быть в списке разрешённых в Amazon: «Управление контентом и устройствами» → «Настройки» → «Персональные документы»);
- через сайт или приложение Send to Kindle, загрузив файл вручную.

Автоматическая отправка письма возможна, только если у Claude Code подключён MCP-инструмент отправки почты. Даже тогда он обязан показать письмо и дождаться вашего «да». Пароли почты в проект не кладите.

## Что изменилось по сравнению с claude.ai

| Было в claude.ai | Стало в Claude Code |
|---|---|
| `/mnt/project/index.json` | `data/index.json` (скрипт ищет её сам; можно задать `PROPOVED_DATA`) |
| `/mnt/user-data/outputs` | `work/YYYY-MM-DD/` для промежуточных файлов, `output/` для готовых |
| `web_fetch` | скрипт `fetch_page.py`: отдаёт текст страницы дословно (`WebFetch` в Claude Code пересказывает страницу моделью, а для зачал и церковнославянского текста это опасно) |
| `present_files` | Claude называет путь к файлу |
| `ask_user_input_v0` (кнопки) | `AskUserQuestion` или нумерованный список в чате |
| Проверка отправки через `tool_search` | список MCP-инструментов (`/mcp`) |
| Список разрешённых доменов сети | не нужен; при блокировке проверьте VPN/прокси |

Исходные версии навыков лежат в `originals-claude-ai/`, если понадобится вернуть их в claude.ai.

## Важно знать

- **Не проверено на живых сайтах.** В среде, где готовился архив, azbyka.ru и radiovera.ru были закрыты (HTTP 403), поэтому `fetch_page.py` проверен на тестовой HTML-странице, а `radiovera_search.py` — только в режиме `--dry-run`. Первый реальный запуск лучше провести на дате, чьи зачала вы знаете, и сверить результат со ссылками в блоке «Источники для проверки». Если разметка azbyka.ru окажется другой, `python3 .claude/skills/propoved-workflow/scripts/fetch_page.py URL --list-ids` покажет доступные id.
- **EPUB на самом Kindle не открывался.** Структура и XML проверены, оглавление и переносы строк в тексте чтения сохраняются.
- **Навыки рассчитаны на запуск из корня проекта** (пути вида `.claude/skills/...`, `work/`, `output/`). Установка их в `~/.claude/skills` (для всех проектов) сломает относительные пути; для такого варианта пути в `SKILL.md` нужно будет заменить на абсолютные.
- **Пересборка данных.** Если нужно обновить `index.json` и `apostol.md` с azbyka.ru: `cd data && python3 apostol_to_md.py build` (скачивает книгу порционно, занимает время).
- **Windows.** В командах вместо `python3` используйте `python` или `py`.
