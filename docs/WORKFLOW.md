# Workflow: от даты до Kindle

**Вход:** дата литургии. Остальное (аудитория, длительность, тон) выясняется в диалоге.

| № | Этап | Навык / инструмент | Результат (файл) | Контрольная точка |
|---|---|---|---|---|
| 1 | Определить чтение | `apostol-zachalo` | `work/ДАТА/01_zachala.md` | подтвердить зачало (рядовое / святого / вариант службы) |
| 2 | Собрать текст чтения | `apostol-chtenie-format` | `02_reading.txt` (прокимны, надписание, зачала с `[Ианн]`/`[СИН]`/`[ЦС]`, аллилуиарии) | нет |
| 3 | Пояснения Радио Вера | `radiovera-apostol` | `03_radiovera.md` («Вариант 1», «Вариант 2»…) | нет |
| 4 | Диалог: что взять и чем дополнить | сам Claude, `references/dialogue.md` | `04_brief.md` | утвердить бриф |
| 5 | План проповеди | сам Claude | `05_plan.md` | утвердить план |
| 6 | Текст проповеди | сам Claude | `06_sermon.md` | сказать «готово» |
| 7 | Сборка и отправка | `build_kindle_doc.py` | `07_kindle.md` → `output/Propoved_ДАТА.epub` | подтвердить отправку |

## Источники данных

- azbyka.ru: богослужебные указания, страница дня, раздел «Чтение Апостола» (читаются скриптом `fetch_page.py`).
- posledovania.ru: запасной источник указаний.
- `data/index.json`: переводы (Ианнуарий, Синодальный) и церковнославянский текст зачал.
- radiovera.ru: пояснения к зачалам (по точной строке поиска).

## Диалог (этап 4)

1. Сводка по каждому варианту радио: мысль, построение, образы, вывод, слабые места, объём в минутах.
2. Вопросы порциями (не больше трёх): какие варианты брать; акцент (нравственный, догматический, практический, пастырский); слушатели, длительность, тон; чем дополнить (отцы, Евангелие дня, память святого, приход); нужен ли призыв к действию.
3. Святоотеческие цитаты проверяются по тексту источника; непроверенное идёт пересказом без кавычек и с пометкой «проверить».
4. Бриф из 6–8 строк на подтверждение.

## Правила

- Писание и богослужебные тексты только из страниц и `data/`, не по памяти.
- Радио Вера только пересказом.
- Письмо отправляется только после явного «да» на конкретное письмо.

## Структура файла для Kindle

```
# Проповедь на <дата>
<подпись дня · отрывок, зач. N>
## Апостольское чтение
## Проповедь
## Источники и заметки   (не для произнесения)
```

## Запуски с середины

- Принесли файл радио → сразу этап 4.
- Принесли готовый текст проповеди → сразу этап 7.
- «Сократи до 5 минут» → этап 6, затем 7.
