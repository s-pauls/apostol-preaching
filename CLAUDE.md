# Проект: подготовка проповеди по Апостолу

Пользователь — православный священник. Проект помогает пройти путь от даты литургии до проповеди на Kindle. Отвечай по-русски.

## Как запускать

- Команда `/propoved <дата YYYY-MM-DD> [аудитория, длительность]` или просто фраза «Подготовь проповедь на 11 октября, 7–8 минут». Работает навык `propoved-workflow`, он вызывает остальные.
- Отдельные шаги: `apostol-zachalo` (какое зачало), `apostol-chtenie-format` (текст чтения с переводами), `radiovera-apostol` (пояснения на radiovera.ru).

## Структура

- `.claude/skills/` — навыки (SKILL.md + скрипты).
- `data/` — `index.json` и `apostol.md` (книга архим. Ианнуария «Апостол», Синодальный перевод и церковнославянский текст), `apostol_to_md.py` для пересборки. Только читать.
- `work/YYYY-MM-DD/` — промежуточные файлы этапов (`01_zachala.md` … `07_kindle.md`).
- `output/` — готовые файлы для Kindle (`Propoved_YYYY-MM-DD.epub`).
- `examples/` — пример входного Markdown для сборщика.
- `originals-claude-ai/` — исходные версии навыков для claude.ai (справочно, не менять).

## Правила, которые нельзя нарушать

1. Номера зачал, тексты Писания и богослужебные тексты берутся только со страниц azbyka.ru и из `data/`. По памяти их не приводить.
2. Страницы azbyka.ru читать скриптом `.claude/skills/propoved-workflow/scripts/fetch_page.py`, а не `WebFetch`: `WebFetch` пересказывает страницу, и можно получить искажённый номер зачала или текст.
3. Святоотеческие цитаты вставлять только после проверки по источнику. Непроверенное — пересказом без кавычек и без имени, с пометкой «проверить».
4. На контрольных точках (зачало, бриф, план, готовый текст, отправка) ждать слова священника.
5. Письма не отправлять без явного «да» на конкретное письмо (адрес, тема, вложение).
6. Материалы Радио Вера — только пересказом, дословно не больше одной короткой фразы.

## Окружение

- Python 3.9+; зависимости: `pip install -r requirements.txt`. На Windows вместо `python3` использовать `python` или `py`.
- Проверка окружения: `python3 check_setup.py`.
